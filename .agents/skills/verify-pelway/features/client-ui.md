## How to get to it (user POV)

利用者はデスクトップのクライアントで #案件B を開き、ハルにメンションし、判断待ちカードで案を選ぶ。現時点ではこの道筋は失敗であり、Electron の開発版が開くことだけを別途確かめられる。

## Driving it with verify-run

`verify-run` からは呼ばない。run の合否にも入れない。GUI を出せるデスクトップ環境で、人が次を確かめる補助手順だけを置く。

```bash
mise run client:bootstrap
mise run client:dev
```

確かめるのは、Electron の窓に「Electron と Octane の土台が動いています。」と出ること。確認したら、`mise run client:dev` を実行した端末で Ctrl+C を押して終える。この手順は観察手順であり、証拠ファイルの形式やスクリーンショットの必須ルールは設けない。正式な E2E の証拠は #762 の自動化で作る。

## Gotchas

- 現在の `mise run client:dev` は Electron の開発版だけを起動する。ローカルの Pelway サーバーを一緒に起動する形は #757 で未完成。
- 起動確認ができても、サーバー接続・画面操作・D1 台本を合格にしない。利用者の道筋全体は、#757・#333・#817・#762 が済むまで失敗のままにする。
- Linux/WSL の `verify-run` で GUI の起動を自動確認できるとは書かない。Windows での D1 リハーサルは #824 で扱う。
- 起動の期待値は現在の `client/apps/desktop/src/renderer/App.tsx` の表示に合わせている。画面の文言を変える変更では、この手順の期待値も同じ PR で直す。
