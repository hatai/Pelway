# 決定事項と未決事項

2026年11月8日（日本時間）時点の設計方針です。「確定」は実装完了を意味しません。

## 確定した方針

| 項目 | 方針 |
| --- | --- |
| サービス | 人間複数と専門AI複数が同じチャンネルで協業する独立したチャット |
| AIの表示 | AIであることを明示し、担当する役割を持たせる |
| クライアント | ブラウザ版と将来のRust製デスクトップアプリを想定する |
| 実行 | VMなどの実行環境と外部ツール連携を検討対象に含める |
| 権限 | 原則として許可制とし、設定によって許可範囲を調整できる方向 |
| 非対象 | 社内wikiと外向けQ&Aの自動生成 |
| ブランド | Pelway名と選定済みA案ロゴを維持する |

## 設計上の提案

判断待ちの一覧、引き継ぎ内容の保存、作業再開時の状態確認をMVP候補として評価します。具体的な仕様と実装範囲は承認前です。

## 統合時にそろえた提案

広い候補を「IT系チーム」、その中の初期検証候補を「取引先と案件を進める小規模チーム」と整理し、主な利用者はプロジェクトリーダー、購入判断者は代表または部門責任者という仮説に統一しました。顧客調査で確かめる前で、確定した市場選定ではありません。

PRDに記載する従来の設計方針も、実装済みの機能ではありません。承認を実行内容に結び付ける方式、外部サービスの結果照合、作業再開、料金はいずれも設計・検証段階です。

## 未決事項

| 論点 | 決めるために必要な確認 |
| --- | --- |
| 最初の顧客と仕事 | 顧客課題、既存手段、利用頻度、支払い意思 |
| MVP | 協業の価値を示す最小フローと失敗時の受け入れ条件 |
| AIの役割 | 依頼の受け手、担当変更、複数AIが発言する条件 |
| 実行環境 | VMとコンテナの分離、停止、再開、保存、削除の要件 |
| 承認 | 外部更新の範囲、承認者、期限、取り消し、再試行の扱い |
| 情報管理 | 企業間分離、保存地域、保持期間、書き出し、削除 |
| 技術選定 | メッセージ保存、配信、実行管理、認証、モデル、外部連携 |
| 原価と料金 | 公式単価、実使用量、待機時間、稼働率、上限停止 |
| 競合 | 曖昧なサービス名の公式URLによる同定と機能範囲 |
| 名称 | 同名の教育AIを含む既存利用の確認と必要な商標確認 |

## 変更の扱い

競合調査から得た改善案は提案として記載し、確定方針へ自動的に格上げしません。比較対象の公開情報が不足する場合は、機能がないと断定せず未確認と記載します。
