# AIの実行は依頼されたチャンネルの読者に結び付け、より広い範囲への投稿は承認を必要にする

AIの1回の実行は、依頼されたチャンネルの読者に結び付ける。結果を書き込めるのは、そのチャンネルか、読者がそれより狭い場所だけにする。より広いチャンネルへ投稿するときは承認を必要にする。社外のゲストがいるチャンネルは「より広い範囲」として扱う。範囲は実行を始めたときではなく、投稿する直前に確かめる。AIの記憶には、どのチャンネルから得たかの範囲を付けて残し、同じ規則で扱う。

チャンネルごとの権限だけでは、非公開のチャンネルで情報を読んだAIが、プロンプトインジェクションや単なる誤りで、その情報を公開のチャンネルへ書いてしまうのを止められない。モデルに「漏らさないこと」を教える方法には頼れないので、投稿の経路で仕組みとして止める。BuzzのInformation flowの設計案と同じ考え方で、Teamsも依頼者しか見られないファイルにもとづく回答を全員に見せる前に確認している。

## Consequences

- チャンネルのメンバーが実行中に増えると、投稿の直前に範囲が広がったと判定され、承認待ちになることがある。
- 記憶の検索は、今の実行の範囲より広いところから得た記憶を返さない。
