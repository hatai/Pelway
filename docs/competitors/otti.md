## 機能

| 観点 | 内容 | 出典 |
|---|---|---|
| 複数人＋AIの同一チャット参加 | 人同士のグループとDMにOttiがいて、名前を呼ぶと会話に加わり、全員に見える形で答える。呼ばれていないメッセージには返信しない。 | [App Store][app] |
| AIの役割・専門性の設定 | AIは「one AI」のOtti 1人。職務別のAIを作る機能は未確認。初動の多さ、見るチャット、静かな時間帯、まとめの時刻、言語などを設定する。 | [App Store][app] |
| 記憶 | 新しい会話を作らず、1本の会話を続ける。グループやDMで話された大事なことも覚える。覚えている内容を見て、直し、消せる。 | [App Store][app] |
| 実行能力 | リマインダー、特定の言葉や名前を見張るトリガー、メールの監視、調査と下書き、目標の計画と進捗管理、Webページの読み取り、投票、通話の文字起こしと要約。 | [App Store][app] [公式サイト][site] |
| 承認・権限管理 | 別のチャット、メール、文書から来た内容を送る前に、カードで確認する（送る／送ってこの人を常に許可／取り消す）。許可した相手と流れは「Authorised recipients」の設定画面に残る。会社に連絡するのは利用者の承認があるときだけと説明。人の紹介は双方の同意を得てから共有チャットを開く。組織としての権限管理は未確認。 | [App Store][app] [公式サイト][site] |
| 自分から動く範囲 | Triggersの「All」タブに、Ottiが自分から行うことをすべて並べ、項目ごとにオン・オフできる。取り込んだチャットごとに、返信する／黙って聞く／関わらない、を選べる。 | [App Store][app] |
| 引き継ぎ | グループに出したタスクを誰かが引き受けると、完了するまでOttiが追う（Hand-offs）。 | [App Store][app] |
| 外部連携 | WhatsAppの接続と同期（引用返信は双方向、WhatsAppで読んだチャットはアプリでも既読、アプリでのミュートはWhatsAppにも反映）、メール。MCPは未確認。 | [App Store][app] |
| 言語 | 英語、ヘブライ語、アラビア語、ロシア語、フランス語、スペイン語、ドイツ語。日本語は一覧にない。 | [App Store][app] |

## UI/UX

| 要素 | 内容 | 出典 |
|---|---|---|
| 画面構成 | チャットの一覧（ピン留め、よく使う、最新の区分）と各チャット。ホーム画面は7種類の背景から選ぶ。 | [App Store][app] |
| AIの見え方 | Ottiはすべてのチャットにいて、名前で呼ぶと全員に見える形で答える。 | [App Store][app] |
| Whisper | どのチャットの上でも、自分だけに見えるOttiとの小さな会話を開ける。開いた画面の内容をOttiが把握し、どの画面で開いたかを表示する。 | [App Store][app] |
| 送信の確認カード | 別のチャット、メール、文書から来た内容を送る前に、送る／送ってこの人を常に許可／取り消すの3択のカードを出す。 | [App Store][app] |
| 提案のカード | Ottiは提案だけをし、ひとりでは動かないと説明。質問をコミュニティに出す、グループを作る、既存のグループに入る、の提案に「はい」か「Not now」で答える。カードは確認前に詳細をすべて表示し、同じカードを二度出さないと説明。 | [App Store][app] |
| Plan room | 目標ごとに、次の一手、Ottiの作業物（調査、構成、下書き）、進捗の記録、Approve / Changeボタンを表示する。Ottiが預かっている項目について、出どころ、決めたこと、次に戻る時期を表示し、元のチャットを1タップで開ける。毎日の報告から目標を開ける。 | [App Store][app] |
| 通話 | 通話中は画面上部に球体（orb）を出し、その下にチャットを表示する。「Otti, quiet」で話すのをやめ、文字起こしと通話内チャットでの回答は続ける。 | [App Store][app] |

## Pelwayとの比較［提案］

この節は本書の整理と提案であり、Ottiの資料が述べている内容ではない。Pelway側は[ビジョン](../vision.md)、[PRD](../prd.md)、[技術](../technical.md)の構想で、実装済みの機能ではない。

| 観点 | Otti | Pelway（構想） | Pelwayでの扱い |
|---|---|---|---|
| 対象 | 個人と友人のメッセージ、WhatsApp | 開発以外を含む小規模チームの業務 | 直接の競合というより、承認と提案のUIの参考にする |
| 人とAIの同席 | グループにAIが1人 | 役割を持つ複数のAI | 複数の専門AIの同席は資料で確認できない |
| 外部送信前の承認 | 送る前の3択カードと、許可した相手の一覧 | 承認を実行内容に結び付ける | 「この人を常に許可」と許可一覧の画面は参考になる。承認後に中身が変わったときの扱いは資料で確認できない |
| 自分から動く範囲の見える化 | Triggersの「All」タブとチャットごとの関わり方 | AIの月の利用上限、権限 | AIが自分から行うことの一覧とオン・オフを、AI社員の設定画面の参考にする |
| 判断待ち・目標 | Plan roomのApprove / Changeと、預かり項目の出どころ・次に戻る時期 | 「今日」画面に誰の判断か・何を決めるかをまとめる | 「出どころ」「次に戻る時期」の表示は判断待ちの一覧の参考になる |
| 個人とAIの会話の共有 | Whisperで個人の会話をチャットの上に開く | 個人とAIの会話を共有する負担を課題仮説にしている | 個人の相談を開いた画面に結び付ける操作を参考にする |
| 引き継ぎ | グループに出したタスクを、引き受けた人が完了するまで追う | 引き継ぎ欄（決定、送信内容、残作業） | 追う対象を状態として持つかは資料で確認できない |
