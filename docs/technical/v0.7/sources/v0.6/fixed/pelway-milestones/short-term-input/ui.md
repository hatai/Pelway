## 人時の根拠・含むもの・除くもの
- **初月の人の時間は約1時間**（U1 0.5h ＋ U2 0.5h）。botの作業時間は人の稼働枠に足さない。
- 除くもの：U3の試験時間（約80分、31〜60日、面談時間の内側）、U4〜U8、UIの実装、試験後の修正。
- 未見積もり：状態図が初月中に変わったときの作り直し（1回あたり0.5h程度と見ているが根拠は過去の確認時間のみで、確定値ではない）。

## 容量が足りないとき
- UIの作業は優先順の最後でよい。**UIの準備ができていないことを理由に面談を止めない**。初月中の面談では状態名の設問を出さず、理解試験は「未実施」と残す。
- 縮小：U2のモックを、結果不明と送信中の2画面だけにする。
- 延期：U1は削らず、遅くとも30日まで。30日を越えると31日以降の試験の開始が遅れるので、遅れた日数を記録する。
- 停止：PRDの状態図が固まらない場合はU1・U2を止め、状態図の確定を待つ（作り直しの無駄を避けるため）。

## 不足していても合意できる条件
- U1が30日までに確認済みであれば、U2が未完成でも初月のUIは「縮小して完了」とする。
- U1も未完成なら、未完了として次月に持ち越し、31〜60日の試験窓の開始を遅らせる判断を事業企画係に任せる。
