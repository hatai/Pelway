## 3) 残る文書必須修正

**V3-01（中）：予約済み・attempt前の編集・失効の遷移が本文と表で食い違う**
- 章・箇所：03「9状態と遷移」の直後の段落、同表「送信中→止まっている」行。
- 根拠：本文は「承認後の編集で…『送信承認待ち』に戻せるのはattempt_started前の未実行操作だけ」とします。一方、表で送信中（予約済み）から送信承認待ちへ戻る行はありません。予約済みの未開始操作は、表では「未送信が確定」した場合に止まっているへ移ります。
- 最小修正：予約前（送信承認待ち）の編集は送信承認待ちへ戻す。予約済みでattempt前の失効・編集は、表の「送信中→止まっている（承認の失効）」だけを使い、送信承認待ちへ直接戻さない、と本文を書き換える。

**V3-02（高）：開始受理のcommitや応答が不明な場合の状態が未定義**
- 章・箇所：03手順7、03遷移表「送信中→止まっている」「送信中→結果不明」、04「外部I/Oの開始受理と復旧」、10 D11の期待値。
- 根拠：手順7は「永続commitを確認できなければ送信せず照合する」とします。しかし遷移表では、止まっているは「未送信が確定」した場合だけ、結果不明は「attempt_started記録後」だけです。受理不明はどちらにも当てはまりません。このままでは、その操作が照合待ちのまま残ります。また、表の「外部呼出直前の再検査」という語は、手順8の「I/O直前の中止検査」と混同されやすいです。
- 最小修正：
  - 遷移表「送信中→結果不明」の条件を「attempt_started記録後、または開始受理（永続commit・応答）が不明で未送信を確定できない場合」へ広げる。
  - 「送信中→止まっている」は「開始受理前の検査で拒否」と書き、I/O前の検査とは区別する。
  - 04の「照合へ回す」の行き先を結果不明に統一する。
  - 10 D11の「前2点は未送信/拒否」を「未送信が確定した場合は未送信/拒否、受理応答不明は結果不明」に合わせる。

**V3-03（低）：判断待ちからの取消で、外部runの停止確認が表から落ちている**
- 章・箇所：03遷移表「判断待ち→止まっている」行と、同表の作業中の取消行。
- 根拠：作業中の行には「外部runが未停止なら停止確認中」の規則があります。判断待ちは11で外部進捗から生じるため、外部runが生きている場合があります。しかし判断待ちの取消行にはこの規則がありません。
- 最小修正：判断待ちの取消行に「外部runが生存する可能性があれば作業中と同じ停止確認規則を適用」と加える。

**V3-04（低）：記録と表記の整合**
- 章・箇所：02冒頭のDiscord段落、09「Discord情報の扱い」、09の依存件数の記録、status。
- 根拠：02は「公開Xで確認した」、09は「公開Xで独立確認し」と書いています。一方、09末尾は保存証拠と担当記録による確認と書いています。静的検査の`dependency_files`は78で、statusのv0.2記録（依存原本74）と異なります。増えた4件の内訳は、今回の材料からは特定できません。
- 最小修正：02・09のDiscord表現を「保存済み公開投稿の取得記録による確認」に統一する。依存件数の差は内訳をstatusかmanifestに書く。

**S1（安全条件の矛盾）：受理後・transport呼出前の取消窓**
- 章・箇所：03手順8、04、長期§6.2（plan-gates抜粋）、長期P1aの「既に外部要求が出た後の試験」。
- 根拠：長期§6.2は「権限取消後に新しい外部操作を出さない」とします。同じ節は、外部要求が出た後の取消を必ず取り消せるとは保証しない、と区別しています。v0.3は、受理commit後に取消がcommitされても、transport呼出を止める保証はないとしています（手順8、ご依頼の「受理以後の取消は撤回保証なし」）。その結果、受理後・呼出前の窓では、取消後に外部操作が出得ます。DBとHTTPは原子的ではないため、この窓は文書だけでゼロにはできません（v0.3もそれを認めています）。
- 判断が必要な点：
  - 窓を長期§6.2の文言に合わせて縮めるのか、§6.2の例外として別判断で認めるのか。
  - 縮める場合の候補は、I/O直前の再確認でgatewayが自ら中止し、その中止を「呼出前の観測」として記録することです。ただし、プロセス死亡の窓は残ります。自己中止を未送信と扱うかは安全判断です。
- 文書側で勝手に緩めたり、§6.2を書き換えたりはしていません。判断はプロダクト担当と濱田さんにお願いします。

**必須修正なし**とは判定しません。上記V3-01、V3-02、V3-03、V3-04と、S1の判断が残ります。
