| ID | 採否 | 修正先 | 理由/残り |
|---|---|---|---|
| CX2-V2-01 / CL2-V2-01 | 採用 | 03開始手順6〜8 / 04試行表 / 01 sequence | 最終検査と条件付き開始を同一transactionへ。一つの成功実行だけtransport資格取得、重複/再起動/応答不明で再取得/自動再送しない。 |

| CX2-V2-04 | 採用 | 08試験対応/安全ゲート | 局所経路の部分試験と全構成試験を分離。実権限/snapshot/隔離等は別見積もり/承認後で既存局所計画へ混ぜない。 |
