**4) 実装前未決として残せる点**

以下は、該当機能への着手・実行を止める条件を維持するなら、未決として残せます。

- T6の正式な期待値、提供元の冪等保証・保持期限・照会証拠と再試行資格。
- 短い自然返信の確定規則、追加遷移、作業中取消案、子task確認、担当交代時の承認継続、承認期限・人数。
- gateway／serverのservice identity、ローカル認証、LAN／TLS／端末認証、bridge認証。
- DB耐久設定・障害モデル、独立照合記録、整合backup・復旧手順、暗号化・鍵管理。
- CLI専用区画、controller／runtime選定、取消後の限定停止・照会権限、Adapter採用試験。
- 固定版の許諾選択・同梱条文・推移依存・NOTICE・SBOM。
- 国内host・全通信経路・3OS／browser・日英の実機確認、国外端末・持出し・外部mailの扱い。

すべてのruntime試験と安全gate判定は未実施のままです。今回の賛成は、文書全体の完成宣言、外観・法適合・性能・国内経路の合格、既存PRD・計画・人時の変更、実データ利用の許可を意味しません。
