## 軽微・提案（直さなくても賛成）
- **TR-5（04 50行）：** stream_posを、workspaceごとの行ロックでcommit順に並べる案は、書き込みが1か所に集まる。07で詰まると分かったときの代替を書いておくとよい。代替は、commit後にoutboxの読み出し側が採番する方式。初版の案はこのままでよい。
- **TR-6（11 62行）：** event IDがないときは、payloadのhashだけで重複と決めず、照会する。これは正しい。Adapterごとの重複判定の規則は、能力定義（`describe_capabilities`）の項目に入れると、追加のAdapterでも漏れない。
- **TR-7（05・10）：** Apple containerで内部専用ネットワークを組めるかは、macOS経路の採用阻害のまま。確認できるまでは、macOSで機密実行をしないと書いてある。これで合っている。
