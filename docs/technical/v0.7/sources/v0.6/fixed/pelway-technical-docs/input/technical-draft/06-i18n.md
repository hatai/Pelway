# 06 日本語・英語対応（最初から）

## 方針（推奨）
- 文言は **Project Fluent**（`.ftl`）で、`locales/ja/*.ftl` と `locales/en/*.ftl`。ネイティブは fluent-rs、Webは @fluent/bundle で**同じファイル**を読む。
- 既定の言語：ユーザー設定 → ワークスペース設定 → OSまたはブラウザの言語。
- 日付・時刻・数値：ICU系（ネイティブは ICU4X、Webは `Intl`）。表示はユーザーの時間帯。保存はUTC。
- 文字列を組み立てない（「〇〇さんが承認しました」は変数つきの1メッセージにする）。複数形や敬語の差は Fluent の選択肢で書く。
- BotやLLMの出力の言語：Botの設定かチャンネルの言語に従う。**翻訳機能は対象外**。

## 日本語で特に試すこと
| 項目 | 試験 |
|---|---|
| IME | 変換中のEnterで送信しない、候補窓の位置、変換中の文字の下線、確定後のカーソル位置（02の検証ゲート） |
| 表示 | 日本語フォントの代替（OS標準。同梱するならライセンスを確認）、行の折り返し（禁則）、全角と半角の混在 |
| 幅 | 英語は長くなりやすく、日本語は短い。ボタンの幅はUI担当の基準で両方確認 |
| 検索 | 日本語の分かち書き（02の全文検索は要確認） |
| 並び替え | 名前の並びは言語ごとに変える（Unicodeの照合） |

## 作業の流れ
- キーを足すときは ja と en を同時に入れる。片方が欠けたら試験で落とす（キーの一覧を比べる簡単な検査）。
- 表示の確認は両言語で画面ごとにスクリーンショットを残す（UI担当のレビュー用）。
