## 推奨構成（1枚で）

| 層 | 推奨（初版） | 位置づけ |
|---|---|---|
| ネイティブGUI（Win/macOS/Linux） | Rust + **Slint**（採用案）。比べる相手はegui、性能の計測にはGPUIも残す。WebViewは使わない | 採用案。実機試験（日本語IME・スクリーンリーダー・大量履歴）とライセンス判断の後に確定 |
| ブラウザ版 | **TypeScript + DOM（React）**のUI ＋ Rustの共通クライアント核を **WASM** で共有 | 推奨。UIは二重実装になる（02で負担を明記） |
| 共通クライアント核 | Rust crate `pelway-client-core`（型・同期・再接続・ローカルキャッシュ・i18nキー） | ネイティブとWebで1つ |
| サーバー | Rust（tokio + axum）、WebSocket + HTTPS | 推奨 |
| DB | PostgreSQL（コンテナ）。クライアント側はSQLite（ネイティブ）/IndexedDB（Web） | 推奨 |
| AI Bot実行 | Rustの **Botランナー** ＋ タスクごとの**使い捨てサンドボックス・コンテナ**。ツールは **MCP（rmcp）** | 推奨。「Botごと常時VM」は採らず、作業場の保存は別に検証（03） |
| LLM | LLMゲートウェイ。試験は**スタブ**、実行の既定は**国内設置ホストのローカル推論**、**外部LLMは国内限定モードで無効・未承認** | 国内限定の追加要件で更新 |
| 国内限定 | 国内設置ホスト前提、**外向き通信は既定拒否**、実行時の許可宛先は空、構築時の取得（依存・イメージ・モデル）と実行時を分ける | 初期条件。適合は未検証（10） |
| 外部送信 | 送信ゲートウェイ経由のみ。承認・冪等キー・結果不明で停止。**国内限定モードでは外部メールは無効**（ダミーメールのみ） | 既存の安全条件を維持 |
| i18n | Project Fluent（`.ftl`）を全クライアント共通、日付・数値はICU系 | 推奨 |
| ローカル開発 | Windows：GUIはWindowsネイティブ、バックエンドは**WSL 2＋コンテナ**。macOS：GUIはネイティブ、バックエンドは**Apple container**（macOS 26・Apple silicon）。Linux：両方ネイティブ＋Podman/Docker | 推奨。ホストでしかできない工程を05に明記 |
