## 一致を確認したもの

- Slint は採用案で、比較の相手は egui。GPUI は Windows の読み上げが使えない問題（zed#41138）があるため採用比較から外す。iced は読み上げ未対応。いずれも README、02、07、08 A1 で ui.md §1〜§2 と一致しています。
- Slint のライセンスを形ごとに整理した表と、master の条文を読んだこと（v1.18.1 と同じかは未確認）。02 の内容は ui.md §1a と一致しています。
- 二重実装の部分工数。Web 32〜62h、ネイティブ 58〜112h、合計 90〜174 人時。これが総工数ではないこと、既存計画に足さないこと、外部連携の表示を含まないこと。02 の内容は ui.md §3a・§8 と一致し、足し算も合っています。
- 390px の承認幅は決めず、既存仕様の不整合として残す（08 の 28 行）。ui.md §3b と一致しています。
- 9状態は増やさない。取り消しは「止まっている＋理由」で表す。停止を確認できるまでは「停止確認中」とし、停止済みには見せない。再接続中や重複して届いたイベントだけでは「結果不明」にしない（03 の 46・67 行、11 の 58〜68 行、08 A5）。ui.md §8 と一致しています。
- 外部から届いた本文の中の偽のボタンや指示を操作にしないこと（11 の 72 行）と、Adapter が持たない能力を「できる」と表示しないこと（11 の 27 行）。
- 外観と配色を変えないこと（06 の 22 行）。AccessKit を組み込んだだけで WCAG に適合したとは言わないこと（06 の 20 行）。
- コピーは止めずに未保証と表示し、ダウンロードは初期状態で無効にする（10 の 29 行）。ui.md §7 と一致しています。
