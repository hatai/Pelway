## 今回のプロ会議の追加所見と採否

根拠は2026-11-09 JSTの今回のルーム投稿である。財務は条件付き採用、法務は設計方針採用可・実データ適法性未確認と評価し、両者は追加調査・再レビュー不要とした。営業は方向性を支持して導入上の補正を提案した。これをv0.2への全員の最終賛同や法的適合認証とは記録しない。

| 入力 | 採否と理由 | 反映先 |
|---|---|---|
| 財務 審査者未確保なら緊急本文アクセスなし | 採用。独立した審査者・守秘・権限を確保するまで非本文対応に限定する推奨。試験導入前に担当・対応時間・復旧限界を確定 | §7、J-S03 |
| 財務 保持は導入先と一つに絞り無期限は保留 | 採用。細かな顧客別設定機能を足さず容量上限と期限を説明。メモリ全件毎月更新は要求しない | §8.1、J-S04 |
| 財務 削除自動化・失敗通知、24時間は内部目標 | 採用。必須制御は維持し、24時間を対外保証にしない。実装は今回対象外 | §8.2 |
| 財務 運用の人件時間も原価へ | 採用。AI再読取と保存量、同意/照会/削除失敗/連携確認の工数を分ける。金額は未算定 | §10後段 |
| 法務① 初期機能の当事者/取得者/代理権/根拠確定表 | 採用。§3.3に未確定と明示した台帳を追加。事実未確認の当事者や根拠を捏造して確定しない。対象機能の実データ利用前に記名・確定し、不足scopeは無効 | §3.3、J-S01/J-S06 |
| 法務② 緊急時の実体的根拠 | 採用。本文を見ない代替の不足と適用根拠の要件を確認。重大障害、一時権限、事後審査だけでは根拠にならない | §7 |
