# demo-check 禁止語リスト（leak-phrases 段階が読む）
# 状態: リード確定 2026-11-09 15:01/15:03（QA案反映済み・数字境界のリテラル先頭修正済み）。変更は開発リードの確定を経る。
# 出典: 開発リードの初期リスト・バックエンド担当の追加・クライアント/QA の英語文言と期限表記の案（2026-11-09）。
#
# 対象ファイル範囲（走査範囲の詳細と除外は lib.sh）:
#   copy  … 利用者向けの文言と外向け文書だけ。
#            - 資産・UI 系ディレクトリのファイルは行全体: assets/ ui/ web/ static/ locales/ i18n/ dist/ target/demo/
#            - 外向け文書: docs/public/（docs/ のそれ以外は内部の仕様・計画文書なので対象外）
#            - UI 系拡張子のファイル（*.html *.css *.js *.ts *.svg *.ftl *.po *.json *.yaml *.md *.txt）は行全体
#            - Rust (*.rs) は "…" の文字列リテラル内だけ（// で始まる行は除く）
#            - ビルド成果物の *.wasm は全体
#   all / secret / ident … 走査範囲のすべてのテキスト（コメント含む）と *.wasm
#
# 書式: <適用範囲><TAB><大文字小文字><TAB><拡張正規表現 (grep -E, UTF-8)>
#   大文字小文字 i = 区別しない、- = 区別する
# 出力はファイル:行と規則だけ。該当行の中身は出さない（秘密値を表示しないため）。

# 「GDPR準拠」と書かない（法的な主張になるため）。出典: リード
all	-	GDPR[[:space:]]*準拠
all	i	GDPR[[:space:]-]*compliant

# 根拠を示せない安全・安心・完了の断定を利用者向けに出さない。出典: リード（日本語）、QA案（英語）
copy	-	暗号化済み
copy	-	安全
copy	-	安心
copy	-	完全に削除
copy	i	\b(secure|safe|encrypted)\b
copy	i	\b(fully|permanently)[[:space:]]+deleted\b

# 漏えい通知の期限（24/72 時間）を利用者向けに出さない。出典: リード・QA案
# 「通知」の近さを問わず 24/72 時間の表記そのものを拾う（以前の「近くに通知」正規表現より厳しい。
# 誤検出があれば QA と合意のうえ例外を足す）。直前が数字なら対象外（1024 hours 等）。
copy	-	(^|[^0-9])(24|72)[[:space:]]*時間
copy	i	(^|[^0-9])(24|72)[[:space:]-]*(hours?|hrs?)([^a-z]|$)

# LLM の API キー用の環境変数名をコードから参照しない（コア AI は国内限定・外部 LLM へ送らない）。出典: バックエンド
ident	-	PELWAY_LLM_API_KEY

# 秘密値の形をしたもの（ビルド成果物を含む）。出典: QA案
secret	-	-----BEGIN[[:space:]]+([A-Z0-9]+[[:space:]]+)*PRIVATE[[:space:]]+KEY
secret	-	Bearer[[:space:]]+[A-Za-z0-9._~+/-]{20,}
secret	-	(^|[^A-Za-z0-9])sk-[A-Za-z0-9_-]{20,}
