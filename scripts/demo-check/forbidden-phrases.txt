# demo-check 禁止語リスト（leak-phrases 段階が読む）
# 状態: QA未合意/暫定。出典: 開発リードの初期リスト＋バックエンド担当の追加（2026-11-09）。QA が追記・修正する。
# 書式: <適用範囲><TAB><大文字小文字><TAB><拡張正規表現 (grep -E, UTF-8)>
#   適用範囲 all   … 走査範囲のすべてのテキスト（コメント含む）
#            copy  … UI 文言だけ: 資産・UI 系ファイルは行全体、Rust (*.rs) は "…" の文字列リテラル内だけ
#                    （// で始まる行は除く）。*.wasm は全体
#            ident … 識別子の参照。走査範囲のすべてのテキストと *.wasm
#   大文字小文字 i = 区別しない、- = 区別する
#
# 「GDPR準拠」と書かない（法的な主張になるため）
all	-	GDPR[[:space:]]*準拠
all	i	GDPR[[:space:]-]*compliant
# 根拠を示せない安心・安全・完了の断定を UI 文言に出さない
copy	-	暗号化済み
copy	-	安全
copy	-	安心
copy	-	完全に削除
# 漏えい通知の期限（24/72 時間）を UI 文言に出さない。数字と「時間/hours」と「通知/notif…」が
# 同じ行の 40 文字以内（" をまたがない）に並ぶものを拾う（順序はどちらでも）。数字の直前が数字なら対象外（1024 等）
copy	i	(^|[^0-9])(24|72)[[:space:]]*(時間|hours?|hrs?)[^"]{0,40}(通知|notif)|(通知|notif)([^"]{0,40}[^0-9"])?(24|72)[[:space:]]*(時間|hours?|hrs?)
# LLM の API キー用の環境変数名をコードから参照しない（コア AI は国内限定・外部 LLM へ送らない）
ident	-	PELWAY_LLM_API_KEY
